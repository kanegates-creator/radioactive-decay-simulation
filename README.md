# Description
A computational simulation script in Python to model multi-stage radioactive decay chains 
$\left(_{}^{47}Ca \rightarrow _{}^{47}Sc \rightarrow _{}^{47}Ti \right)$
and evaluate system sensitivity to variations in isotopic half-lives.

# Instructions
* Install numpy
* Install matplotlib
* run python decay_kinetics_simulation.py
